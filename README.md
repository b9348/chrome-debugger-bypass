# 断点绕过助手

当前版本：1.1.0

这是一个 Manifest V3 Chrome 扩展，用于跳过网页通过 `debugger` 语句制造的反调试暂停。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `chrome-debugger-bypass`。

## 使用

1. 打开需要检查的网页。
2. 点击扩展图标，开启“保护当前网站”，或开启“所有网站自动保护”。
3. 刷新网页，再按 F12 打开开发者工具。

扩展会通过 Chrome Debugger Protocol 跳过所有 JavaScript 暂停，并在页面脚本执行前清理常见的动态 `debugger` 代码。启用时 Chrome 可能显示“此标签页正在被调试”的提示，这是 `chrome.debugger` 权限的正常行为。

## 限制

- `chrome://`、Chrome 扩展商店等浏览器内部页面不能被扩展修改。
- 跳过全部暂停也会让普通断点暂时失效；需要自己调试代码时，请先关闭该网站的保护。
- 个别网站可能依赖对 `eval` 或 `Function` 的原生特征检测。如页面异常，可关闭“动态脚本清理”，仅保留断点跳过。
